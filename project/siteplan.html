PsychKy Gaming Website Plan

Site Name

PsychKy Gaming

I chose the name PsychKy Gaming because PsychKy is the name of my gaming YouTube channel. Using the same name will make the website easy for viewers to recognize and connect with my other social media accounts.

Possible domain name: psychky.com

Site Purpose

The purpose of the PsychKy Gaming website is to provide a central location where viewers can learn about the PsychKy Gaming YouTube channel. The website will feature recent videos, information about the creator, frequently asked questions, social media links, and a way for viewers or potential sponsors to make contact.

Scenarios

  • Where can I watch the newest PsychKy Gaming video?
  • What types of League of Legends videos does PsychKy create?
  • How often does PsychKy upload new videos?
  • How can I contact PsychKy about a question, collaboration, or sponsorship?

Typography

Bowlby One SC

This font will be used for major headings and titles. Its bold appearance matches the same vibe and style of the PsychKy Gaming banner that I already have.

Roboto

This font will be used for paragraphs, navigation links, buttons, and other general website content because it is clean and easy to read.
